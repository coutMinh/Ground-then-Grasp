# Paper deliverable (after experiments)

Use the official CVPR author kit and keep the entire English PDF within two
pages, references included. Required parts: abstract, introduction, related
work, method, experiments, conclusion and references; include equations,
at least one figure/table and the actual public GitHub URL.

Author/affiliation and submission filename require user input. Do not infer them
from the GitHub account. Do not write experimental claims before registered
benchmark results exist. Published baseline numbers must be cited and separated
from self-run results on a different subset/protocol.

Main planned evidence: matched ablations, oracle-mask diagnostic, method diagram,
and qualitative examples including failures. Label-noise findings in the data
audit must be acknowledged. No CVPR template or bibliography is fabricated here.
